# Chai Atlas – Mini E-Commerce App

A beginner capstone: a tea shop with a product catalog, shopping cart and checkout preview. Plain HTML, CSS and JavaScript, with no build step.

## Run it
Open `index.html` in any browser.

## Features
- Products rendered dynamically from a JavaScript array (`PRODUCTS` in `script.js`)
- Category filter
- Add to cart, change quantities, remove items, empty cart
- Live item count and total price
- Modal checkout preview with subtotal, shipping, tax and grand total
- Cart saved in `localStorage`, keyboard accessible (Esc closes panels)

## Ideas to extend
- Add a search box or sort by price
- Add a promo-code input
- Swap emojis for product photos

## Product images
Images live in `images/` and are set with the `image` field of each product in `script.js`. They are illustrated SVG pouches; replace them with real photos (e.g. `images/tea-1.jpg`) by changing that path.
